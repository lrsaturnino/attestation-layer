## Evidence Labels

Alpha may use `TYPE_CHECKED`, `STATICALLY_RESOLVED`, `REVIEWED`, and
`BOUNDED_CHECKED`.

Beta adds `TRACE_VALIDATED`, `SMT_CHECKED`, and `CONSISTENCY_CHECKED`.

Conclusion may use `PROVEN_INDUCTIVE` only when a registered proof-producing
backend emits it.
