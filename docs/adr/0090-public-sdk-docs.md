# ADR 0090: Public SDK, Documentation Versioning, And External Integration Contract

## Status

Proposed

## Context

External users need a stable map from tasks to docs and schemas.

## Decision

Add a public documentation index with docs, audiences, examples, and schema
references.

## Consequences

Docs can be versioned with the code and referenced by release certification.

## Validation

`nlreq public-docs-index` emits the default index.
