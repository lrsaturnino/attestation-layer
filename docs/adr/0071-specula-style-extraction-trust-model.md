# ADR 0071: Specula-Style Extraction Trust Model And Promotion Workflow

## Status

Proposed

## Context

Generated specs can help fill brownfield gaps but cannot be trusted without
review.

## Decision

Candidate specs remain `draft`, `unknown` freshness artifacts. Promotion
requires an approved content hash and reviewed registry entry.

## Consequences

Generated specs can accelerate work without satisfying proof closure alone.

## Validation

Existing spec extraction reports candidate gaps and promotion checks approved
hashes.
