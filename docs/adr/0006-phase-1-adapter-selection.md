# ADR 0006: Phase 1 Adapter Selection

## Status

Deferred

## Context

Phase 1 must choose one real adapter after the Phase 0 core is working. Choosing too early risks letting one ecosystem distort the core architecture.

## Decision

No real adapter is selected before Phase 0 completion. At the end of Phase 0, this ADR must be updated to name:

- selected ecosystem,
- rationale,
- expected adapter-specific tooling,
- evidence types targeted in Phase 1,
- reviewer availability,
- and known setup risks.

## Consequences

Phase 0 remains adapter-neutral. Phase 1 starts with an explicit, reviewed adapter decision instead of implicit drift.
