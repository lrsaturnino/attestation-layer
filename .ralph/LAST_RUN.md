# Iteration summary — 2026-06-04T07:41:01Z
## Implementation summary
- **PA-5 CLI wiring (front-door complete):** Added `--ensemble-client CLIENT` (repeatable) to the `semantic-translate` command (`cli.py`). Accepts `live`, `live:<model-id>`, and `recorded:<fixture-path>` specs. Builds the `decomposition_clients` list and passes it to `translate_controlled_requirement_to_formal_claim()`. Unknown spec returns exit-code 2 with an informative message.
- **Source span remapping:** Added `_remap_disagreement_spans_to_original()` in `semantic_translation.py`. Resolves each `TranslationDisagreement.path` against the original parsed `requirement_ir` via the now-public `spans_for_path()` (formerly `_spans_for_path` in `translator_agreement.py`). When the path resolves in the original IR, the original spans replace candidate spans. When it does not (structurally diverged candidate), the candidate spans are kept and an explicit `(span-fallback: …)` note is appended to `reason`. `_check_decomposition_ensemble` calls this before `refuse_ambiguous_ensemble`.
- **Mocked-SDK tests for AnthropicDecompositionClient:** Added four new tests in `test_decomposition_client.py` using `types.ModuleType` + `MagicMock` to inject a fake `anthropic` module into `sys.modules` (package not installed in dev env). Tests cover: IR returned from parseable DSL v3 response; `model_id`/`prompt_hash`/`source_text_hash` populated; `is_audited=False`/`approval=None` invariant; prompt contains `requirement_id`, `title`, and `controlled_text`.
- **Span-remap integration test:** Added `test_refused_ambiguous_source_spans_from_original_ir` asserting that every span in NLR-REFUSED-AMBIGUOUS findings is traceable to the original parsed IR.
- **`spans_for_path` exposed publicly** in `translator_agreement.py` (was `_spans_for_path`); private alias kept for any remaining internal callers.
