## Issues found
- The new CLI cannot actually produce the claimed recorded-fixture `NLR-REFUSED-AMBIGUOUS` path. `recorded:<path>` loads a bare `RequirementIRV2` and constructs `RecordedDecompositionClient(fixture=fixture_ir)` with default trust metadata at `src/nlreq/cli.py:2187`-`2190`; those defaults are `approval=None` and `is_audited=False` in `src/nlreq/decomposition_client.py:104`-`135`. `_check_decomposition_ensemble()` blocks any such candidate as `NLR-UNAUDITED-DECOMPOSITION` before signature comparison at `src/nlreq/semantic_translation.py:420`-`455`, so two disagreeing `recorded:` fixtures from CLI cannot reach the ambiguity refusal.
- The end-to-end gate still uses the older low-provenance disagreement-refusal path. When `translation_agreement` is supplied, it calls `build_translation_agreement_report()` and then `refuse_ambiguous_ensemble(requirement_id=..., disagreements=...)` without input hashes, prior stages, parsed IR, semantic decomposition, or span remapping at `src/nlreq/end_to_end_gate.py:247`-`295`. The span/provenance fix applies to the semantic-translation ensemble path, not this gate artifact path.
- PA-6 remains unimplemented. `AnthropicDecompositionClient` still documents and returns `approval=None` and `is_audited=False` until a future audit exists (`src/nlreq/decomposition_client.py:151`-`153`, `:207`-`215`); there is no second-model rubric, no planted invented-premise audit fixture, and no path that can turn live decompositions into audited candidates.
- PA-1 and PA-2 remain blocking. `SystemSpecAssumptions == TRUE` means `S` is not conjoined with `R` (`src/nlreq/system_checker.py:301`-`317`), `formal_claim_smt` intentionally excludes predicate fragments (`src/nlreq/formal_claim_smt.py:12`-`34`), and no bounded `apalache` result is produced for `rejection_order` routes even though those route to `BOUNDED_CHECKED` / `apalache` in `src/nlreq/formal_claim.py:330`-`355`.
- The new span-remap test is too weak for the production failure mode. `tests/test_decomposition_client.py:471`-`496` uses `ir_a` and a mutated copy `ir_b` parsed from the same `_CONTROLLED_TEXT`, so candidate spans are already original-text spans; the assertion at `tests/test_decomposition_client.py:504`-`510` does not prove model-output spans are replaced or that the fallback reason is emitted when a path is absent from the original IR.
- PA-3, PA-7/PA-8, PA-9, and PA-11 are still materially incomplete. Temporal lowering still has `Within(event, amount, unit) == event` in the deprecated skeleton at `src/nlreq/translator.py:275`-`294`; requirement-set consistency still uses only the six-entry `opposites` table and `opposite_predicate` type at `src/nlreq/system_checker.py:34`-`40` and `:217`-`246`; the requirements translation corpus still has only three cases with no domains or source languages (`benchmarks/requirements-translation/corpus.json:1`-`51`).
## Recommended actions
- Fix the `recorded:` CLI path by accepting an explicit `DecompositionResult` or metadata-bearing fixture, not just a `RequirementIRV2`. Preserve the trust boundary: do not synthesize approval in the CLI; require the fixture to carry explicit human approval and audit status. Add CLI-level tests for two approved+audited recorded clients disagreeing to `NLR-REFUSED-AMBIGUOUS`, two unaudited recorded clients to `NLR-UNAUDITED-DECOMPOSITION`, and an unknown spec to exit 2.
- Reuse the same provenance-rich refusal path in the end-to-end gate: remap disagreement spans against the original `requirement_ir`, pass prior artifacts/input hashes into `refuse_ambiguous_ensemble()`, and record the parsed IR/decomposition on the `translation_refusal` artifact.
- Implement PA-6 next: audit-client interface, recorded audit fixtures, live second-model rubric, invented-premise negative test, and package/gate provenance. Audit may set `is_audited=True`; it must not mint human `Approval`.
- Close PA-1/PA-2 before claiming SP2: conjoin real `S` with `R`, run a checker-backed requirement-vs-negation discriminator, and produce fragment-bound backend results for every FormalClaim route, including `rejection_order`.
- Strengthen span-remap tests with candidate spans from a different synthetic/model-output document and with a structurally divergent path that forces the fallback note.
- After the audit and tracer bullet are real, implement PA-3 bounded temporal lowering, PA-7/PA-8 FormalClaim contradiction taxonomy plus set-SMT, and the PA-9/PA-11 multi-domain/multilingual corpus metrics.
